A browser-sized mapping studio.

Rayality Mapping Pro is created by Ray Tsai for experimenting with projection geometry and local media without a dedicated desktop installation.

The core tool is open source under MIT. It is provided as-is, without a guarantee of show-critical reliability. Rehearse your setup and keep backups. Use only media you own or have permission to display. Google and Vercel do not endorse this project.

Help improve it

Report a reproducible issue or contact the maintainer. Include browser version and steps, but never API keys, private footage or financial details. See the repository's contribution guide for development setup.
