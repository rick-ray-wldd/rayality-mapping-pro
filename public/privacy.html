Privacy & local storage

Effective 3 October 2026. This describes the official ad-disabled release; a fork or future release may have different practices.

Your projects stay in this browser

Local images, videos and geometry are stored in IndexedDB on your device. The editor shares project state with same-origin output tabs using BroadcastChannel and localStorage. No project upload service, account system or analytics is included. Exported project files contain your media: share them only with people you intend to receive that content.

Optional Google AI

Saving a key makes no API request. A key you enter is kept in sessionStorage for this tab session, accessible to scripts running on this origin. It is not an encrypted vault. Legacy keys in localStorage are removed when the AI panel opens. Use Clear Key in that panel to remove the current key. Browser session restore behavior may retain session data.

Choosing Generate sends your prompt and optional reference image directly to Google's Gemini API; Google receives the API key and normal network metadata, and may bill your Google project. Generated media is downloaded to the browser. Review Google's Gemini API terms before use. No owner key is supplied by the site.

Hosting and advertising

The hosting provider receives normal web requests, including IP address and browser headers, to deliver the site. This release loads no advertising or analytics services. No advertising cookies are set by this application. Before enabling AdSense, the operator must update this notice with the actual providers and data practices and implement the required consent and withdrawal controls. Third-party ad providers may then use cookies, web beacons and IP addresses to serve and measure ads; that feature is currently disabled.

Delete or back up data

Export a project before clearing site data. Use your browser's site settings to delete IndexedDB, localStorage and session data for this origin. No server copy is available for recovery. A different domain or browser profile has separate storage.
